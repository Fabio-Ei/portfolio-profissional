# Portfólio profissional

Portfólio profissional desenvolvido como atividade acadêmica da disciplina **Design Profissional**.

O projeto apresenta a formação, competências, interesses e um projeto desenvolvido durante a formação em Análise e Desenvolvimento de Sistemas.

---

## Sobre o projeto

Este portfólio foi desenvolvido utilizando HTML5 e CSS3, com foco em uma apresentação profissional, organização das informações, responsividade e acessibilidade.

O projeto apresenta informações sobre a trajetória acadêmica e profissional de **Fabio Yokomizo**, além de um projeto desenvolvido durante sua formação técnica.

O portfólio utiliza uma estrutura simples, sem frameworks, JavaScript, banco de dados ou formulários de armazenamento de dados.

---

## Objetivos

Os principais objetivos do projeto são:

- Criar uma apresentação profissional para uso acadêmico e profissional;
- Organizar informações sobre formação e competências;
- Apresentar um projeto desenvolvido durante a formação em Análise e Desenvolvimento de Sistemas;
- Desenvolver uma página responsiva;
- Aplicar conceitos de HTML5 semântico e CSS3;
- Aplicar conceitos de acessibilidade;
- Publicar o portfólio gratuitamente utilizando o GitHub Pages.

## Estrutura do portfólio

O projeto está organizado da seguinte forma:

portfolio-profissional/
│
├── index.html
├── style.css
├── README.md
│
└── assets/
    └── projeto-01.png

### Arquivos

**`index.html`**

Contém a estrutura e o conteúdo principal do portfólio.

**`style.css`**

Contém os estilos visuais, layout, responsividade, cartões, botões e estados de foco.

**`README.md`**

Contém a documentação do projeto.

**`assets/`**

Diretório destinado às imagens utilizadas no projeto.

**`projeto-01.png`**

Espaço reservado para uma imagem do projeto apresentado. A imagem ainda não está disponível.

## Como executar localmente

Para executar o projeto localmente:

1. Faça o download ou clone este repositório.
2. Abra a pasta `portfolio-profissional`.
3. Verifique se o arquivo `index.html` está na raiz do projeto.
4. Abra o arquivo `index.html` em um navegador.

Também é possível abrir a pasta do projeto no Visual Studio Code e utilizar a visualização disponível no ambiente de desenvolvimento.
